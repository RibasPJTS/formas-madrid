# Fôrmas Madrid – Canteiro

Página de canteiro (Projetse) para acompanhar os painéis de fôrma metálica: planta, 3D, elevações e status por ciclo.

Abra no celular, toque em **Compartilhar → Adicionar à Tela de Início** (iPhone) ou **⋮ → Adicionar à tela inicial** (Android). Depois do primeiro acesso funciona sem internet. Os status ficam salvos no aparelho.
