Ciclo de concretagem

Cada uso do jogo de fôrmas (ex.: 2º pav. – apto 201) é um ciclo. O status de cada painel é marcado dentro do ciclo.

Dados e cópias

Tudo fica salvo neste aparelho automaticamente, sem internet. Para guardar uma cópia, faça o download; para juntar com outro aparelho, faça o upload do arquivo dele (nada é apagado).
